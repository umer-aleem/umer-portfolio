Career journey

From quality engineering to Principal Data Engineering.

Eight years, five roles, one throughline: understanding how data actually moves through an organization before writing a single pipeline.

2025 — Present

Principal Data Engineer

  • Own the architectural direction for enterprise data platforms spanning ingestion, transformation, warehousing and AI-ready data consumption.
  • Set standards for data quality, governance and reliability across pipelines built on AWS, Azure and Microsoft Fabric.
  • Advise on how AI and natural-language interfaces can be layered on top of trusted enterprise data.
  • Mentor engineers on data modeling, orchestration and performance optimization practices.
2024

Senior Data Consultant

  • Designed Microsoft Fabric data platforms — Data Factory, Lakehouse, PySpark and semantic models — to support forecasting and supply-chain visibility.
  • Advised clients on data lake and warehouse architecture decisions across AWS and Azure.
  • Worked directly with business stakeholders to translate reporting and analytics requirements into data models.
2021

Senior Data Engineer

  • Built enterprise data lake and warehouse architecture using AWS S3, Glue, EMR Spark, Athena and Snowflake.
  • Delivered a real-time healthcare data platform using Kafka and CDC-based ingestion for near-real-time patient monitoring.
  • Built a migration framework using Python, AWS S3, Aurora RDS and Snowflake to modernize legacy and NoSQL data.
  • Implemented data quality frameworks using Great Expectations and AWS Deequ for validation, null and date-field checks, and pipeline testing.
  • Optimized a core process from roughly 4,800 database queries down to approximately 400, contributing to a 55% reduction in process runtime.
2020

SQA Engineer

  • Owned quality assurance for data-intensive applications, building a deep understanding of how data issues surface downstream.
  • Began transitioning into development and data engineering, picking up Python, SQL and automation skills alongside QA responsibilities.
  • Built OCR, NLP and API-based processing pipelines for an automated parcel address recognition workflow.
2019

Research Officer

  • Started a career in technology through applied research, developing the analytical foundation that later carried into data engineering.
  • Contributed to work later recognized with an IEEE research publication.
